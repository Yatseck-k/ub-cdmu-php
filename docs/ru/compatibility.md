# Совместимость и происхождение

[English version](../compatibility.md)

Для CLI нужен Python 3.12+, для анализатора — PHP 8.2+; Docker содержит оба. Зависимость парсера — `nikic/php-parser` 5.x с лицензией BSD-3-Clause. Лицензия этого репозитория — MIT. Алгоритмы и форматы EDN Crapper и Dryer изучались по исходным репозиториям с лицензией 0BSD; их код сюда не скопирован. При распространении сохраняйте уведомления о лицензиях зависимостей.

Парсер v0.1 проверен на обычном PHP и небольших образцах синтаксиса в стиле Laravel, Symfony и Yii. Это примеры синтаксиса, а не полноценные приложения на фреймворках. Возможность парсера принять новый синтаксис целевого PHP не зависит напрямую от версии среды PHP. Проект не заявляет поддержку Windows или точное покрытие ветвей.

Поля `:entries` в EDN Crapper: `:name`, `:namespace`, `:complexity`, `:coverage` и `:crap`. Экспортируются именованные функции и методы; замыкания, стрелочные функции и методы анонимных классов остаются в JSON, поскольку их синтетические имена нельзя сопоставить в исходном просмотрщике. Неизвестные покрытие и CRAP обозначаются `nil`. Это отличается от запасного значения 0% в исходном инструменте при отсутствии отчёта и требуется нашей спецификацией. EDN Dryer использует `:candidates` с оценкой сходства, языком `"php"`, границами строк и числом узлов. Для интеграций основным форматом служит JSON. Infection/Mutator и UML Viewer не реализованы в v0.1.
