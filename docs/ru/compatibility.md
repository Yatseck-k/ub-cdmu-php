# Совместимость и происхождение

[English version](../compatibility.md)

Composer-пакету нужны PHP 8.2+, Composer 2 для установки и расширения PHP DOM и JSON. Зависимости времени выполнения: `nikic/php-parser` 5.x и `symfony/yaml` 7.4. Git нужен только для `--changed`. Python и Docker не требуются. Лицензия репозитория — MIT, парсера — BSD-3-Clause, Symfony YAML — MIT. Алгоритмы и форматы EDN Crapper и Dryer изучались по исходным репозиториям с лицензией 0BSD; их код сюда не скопирован. При распространении сохраняйте уведомления о лицензиях зависимостей.

Парсер проверен на чистом PHP и небольших синтаксических образцах Laravel, Symfony и Yii. Это не полноценные приложения фреймворков. Возможность парсера принять более новый синтаксис не равна версии PHP, на которой запускается инструмент. Проект пока не заявляет поддержку Windows или точное покрытие ветвей.

Поля Crapper EDN `:entries`: `:name`, `:namespace`, `:complexity`, `:coverage`, `:crap`. Экспортируются именованные функции и методы; замыкания, стрелочные функции и методы анонимных классов остаются только в JSON, потому что исходный viewer не сопоставит их синтетические имена. Отсутствующие покрытие и CRAP записываются как `nil`, в отличие от исходного значения 0% при отсутствии отчёта; это требование нашей спецификации. Dryer EDN использует `:candidates` с оценкой, языком `"php"`, диапазонами строк и числом узлов. JSON — основной формат интеграций. Infection/Mutator и UML Viewer в v0.1 не реализованы.
