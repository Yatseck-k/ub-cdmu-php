# CLI и конфигурация

[English version](../cli.md)

Запускайте `vendor/bin/ub-php` из корня анализируемого проекта. Глобальные параметры `--root PATH` и `--config PATH` указываются перед командой. `doctor` проверяет PHP, доступность парсера и YAML-зависимости и каталог проекта. `check` запускает включённые проверки Crapper и Dryer; `crap` и `dry` запускают по одной. Каждая команда принимает `--format text|json`; команды проверки принимают `--changed`, а `crap` и `dry` также `--threshold NUMBER`. Параметр `--changed` включает добавленные и изменённые PHP-файлы из индекса Git, рабочего дерева и неотслеживаемых путей в настроенных каталогах.

Необязательная `.ub-mode.yaml` использует `version: 1`; пример находится в репозитории. Каталоги `project.source` используются, только если существуют. Полное сканирование без PHP-файлов возвращает ошибку; `--changed` без изменённых PHP-файлов завершается успешно с пустым отчётом. Пути из `project.exclude` исключаются на любом уровне дерева. `crapper.coverage.path` указывает на готовый отчёт Clover XML. Если его нет, покрытие остаётся неизвестным. По умолчанию отчёты пишутся в `.metrics/`. CLI не запускает PHPUnit или Pest и не изменяет исходный код.

Коды выхода: `0` — анализ пройден (в том числе при предупреждениях Dryer или неизвестном покрытии); `2` — известный CRAP достиг порога; `3` — ошибка среды, конфигурации, разбора или отчёта; `4` — неверные параметры CLI. JSON детерминирован при неизменных входных данных. Git нужен только для `--changed`.
