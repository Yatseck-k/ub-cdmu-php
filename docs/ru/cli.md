# CLI и конфигурация

[English version](../cli.md)

По умолчанию все команды запускаются из корня проекта. Глобальные параметры `--root PATH` и `--config PATH` указываются перед командой. `doctor` проверяет доступность Python, PHP, анализатора и зависимостей Composer. `check` запускает включённые проверки Crapper и Dryer; `crap` и `dry` запускают по одной проверке. Каждая из них принимает `--format text|json` и `--changed`; `crap` и `dry` также принимают `--threshold NUMBER`. Параметр `--changed` включает добавленные и изменённые PHP-файлы из индекса Git, рабочего дерева и неотслеживаемых путей в настроенных каталогах исходного кода.

Необязательный файл `.ub-mode.yaml` использует `version: 1`; пример есть в репозитории. Каталоги `project.source` используются только при их наличии. Полный поиск без PHP-файлов считается ошибкой; `--changed` без изменённых PHP-файлов успешно создаёт пустой отчёт. Пути `project.exclude` исключаются на любой глубине дерева. `crapper.coverage.path` указывает на существующий XML-отчёт Clover. Если отчёта нет, покрытие остаётся неизвестным. По умолчанию отчёты записываются в `.metrics/`. CLI не запускает PHPUnit или Pest и не меняет исходные файлы.

Коды завершения: `0` — анализ прошёл, включая предупреждения Dryer или неизвестное покрытие; `2` — известное значение CRAP достигло настроенного порога; `3` — ошибка окружения, конфигурации, протокола, разбора или записи отчёта; `4` — неверный синтаксис команды. При неизменных входных данных JSON-вывод детерминирован.
