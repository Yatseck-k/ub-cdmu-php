# Архитектура и контракт

[English version](../architecture.md)

`vendor/bin/ub-php` выбирает PHP-файлы в настроенных каталогах. Анализатор разбирает их с помощью `nikic/php-parser`, не загружая и не выполняя целевой код. В том же процессе PHP проверяется конфигурация, читается необязательный отчёт Clover, вычисляются CRAP и сходство Жаккара, применяются пороги и записываются отчёты JSON/EDN. Межъязыкового процесса и промежуточного JSON-протокола анализатора больше нет.

Единица анализа содержит устойчивый `id` на основе исходного кода, относительный POSIX-путь `file`, `namespace` (включая класс для методов), `name`, `kind`, границы строк включительно, `complexity`, `node_count` и нормализованные признаки AST `features`. В `id` входят путь и начальная строка; переименование или перенос единицы создаёт новый `id`. Канонический отчёт сохраняет поля `schema_version: "1.0"`, `tool`, `entries`, `candidates` и `diagnostics` для интеграций.

Отчёты сортируются и атомарно заменяются после успешного анализа. Ошибка разбора возвращает код 3 и сохраняет прежние отчёты. JSON — канонический формат, EDN экспортирует формы исходных инструментов. Каталог отчётов исключён из сканирования исходников.
