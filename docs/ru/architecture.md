# Архитектура и контракт

[English version](../architecture.md)

`ub-php` находит PHP-файлы в настроенных каталогах исходного кода и передаёт один JSON-запрос в стандартный ввод `php/analyzer/bin/analyze.php`: `{"schema_version":"1.0","root":"/absolute/project","files":["src/A.php"]}`. Анализатор разбирает каждый файл с помощью `nikic/php-parser` и возвращает через стандартный вывод `schema_version`, `units` и `diagnostics`. Ошибки разбора попадают в `diagnostics`; некорректные запросы приводят к ошибке в стандартном потоке ошибок. Python проверяет ответ перед расчётом метрик. Схема: `src/ub_mode_php/contracts/analyzer-v1.schema.json`.

Единица анализа содержит устойчивый `id` на основе исходного кода, относительный POSIX-путь `file`, `namespace` (включая класс для методов), `name`, `kind`, границы строк включительно, `complexity`, `node_count` и нормализованные признаки AST `features`. В `id` входят путь и начальная строка; переименование или перенос единицы создаёт новый `id`. PHP-анализатор не выполняет и не изменяет целевой код. Python отвечает за конфигурацию, импорт Clover, сравнение по коэффициенту Жаккара, пороги и отчёты.

Отчёты сортируются и атомарно заменяются после успешного анализа. При ошибке разбора команда завершается с кодом 3 и не создаёт новые отчёты. JSON — канонический формат; EDN экспортируется для форматов исходных инструментов. Каталог отчётов исключён из поиска исходного кода.
