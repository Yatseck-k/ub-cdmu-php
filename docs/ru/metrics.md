# Правила расчёта метрик

[English version](../metrics.md)

## Crapper

Цикломатическая сложность каждой функции, метода, замыкания и стрелочной функции начинается с 1. Добавляется по 1 за каждый `if`, `elseif`, `for`, `foreach`, `while`, `do`, `catch`, вариант `case` или `match` кроме `default`, тернарный оператор, `&&`, `||`, логические `and`/`or` и `??`. Вложенные функции и замыкания получают собственную оценку. Абстрактные методы и методы интерфейсов без тела пропускаются.

Исполняемые строки задаются элементами Clover `<line type="stmt">` внутри границ единицы анализа включительно. Покрытие — процент строк с числом выполнений больше нуля; это покрытие строк, а не ветвей. Если отчёта нет, единица не сопоставлена с отчётом или у неё нет исполняемых строк, покрытие неизвестно. Для известного процента покрытия `P` используется формула `CRAP = CC² × (1 − P/100)³ + CC`. При неизвестном покрытии в JSON записывается `crap: null`, а в EDN — `nil`. Известное значение CRAP от 10 включительно не проходит проверку с порогом по умолчанию.

## Dryer

Кандидатами считаются только обычные функции и конкретные методы длиной не менее 4 строк исходного кода и с не менее чем 20 нормализованными узлами AST. Имена локальных переменных и литералы игнорируются; структура AST, операторы и имена прямых вызовов сохраняются. Сходство — отношение размера пересечения множеств признаков к размеру их объединения (коэффициент Жаккара). Порог отчёта по умолчанию — 0.82; кандидаты выводятся как предупреждения и не проваливают CI. При проверке агентом `ub-mode` можно явно задать 0.8. Замыкания и стрелочные функции не участвуют в сравнении на дублирование в v0.1.

Нормализация эвристическая: проверьте найденные пары перед рефакторингом. JSON содержит идентификаторы и дополнительные поля; `.metrics/crap.edn` следует [формату Crapper](https://github.com/unclebob/crapper), а `.metrics/dry.edn` — [формату Dryer](https://github.com/unclebob/dryer). Для совместимости с просмотрщиками EDN экспортирует только те поля и имена, по которым эти форматы могут сопоставить записи.
