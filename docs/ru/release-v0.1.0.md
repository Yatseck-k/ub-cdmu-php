# Примечания к выпуску v0.1.0 (черновик)

[English version](../release-v0.1.0.md)

- Composer-пакет и CLI только на PHP с версионированными отчётами JSON.
- Оценки CRAP по статической сложности и готовому покрытию строк Clover; отсутствие покрытия остаётся неизвестным.
- Предупреждения о структурном дублировании с настраиваемым порогом Жаккара и отчётами JSON/EDN.
- Выбор изменённых файлов и тесты CI на PHP/Composer. Примеры интеграции с агентами поддерживаются в отдельном репозитории `ub-mode-php`.

Известные ограничения: нет автоматического сбора покрытия, мутационного тестирования, визуализации UML и поддержки Windows. Проверка фреймворков использует небольшие синтаксические образцы. Этот черновик станет примечанием к выпуску после прохождения всех проверок v0.1.
