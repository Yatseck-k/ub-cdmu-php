# Примечания к выпуску v0.1.0 (черновик)

[English version](../release-v0.1.0.md)

- CLI на Python и анализатор PHP AST с версионированным JSON-протоколом.
- Оценки CRAP по статической сложности и готовому отчёту Clover о покрытии строк; отсутствие покрытия остаётся неизвестным значением.
- Предупреждения о структурном дублировании с настраиваемым порогом коэффициента Жаккара и отчётами JSON/EDN.
- Выбор изменённых файлов, запуск в Docker и тесты CI. Примеры интеграции с агентами поддерживаются в отдельном репозитории `ub-mode-php`.

Известные ограничения: нет автоматического сбора покрытия, мутационного тестирования, визуализации UML и поддержки Windows. Проверка фреймворков основана на небольших образцах синтаксиса. Этот черновик станет примечаниями к выпуску только после прохождения всех проверок для v0.1.
