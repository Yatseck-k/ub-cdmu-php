# Правила репозитория

## Структура проекта

Composer-пакет, CLI на PHP, логика метрик, конфигурация и AST-анализатор, который не изменяет исходный код, находятся в `src/`. `bin/ub-php` — исполняемый файл Composer. Тесты PHP расположены в `tests/`, небольшие проекты с образцами синтаксиса — в `fixtures/`, описание метрик и команд — в `docs/`. Необязательный скилл и примеры интеграции для агентов находятся в отдельном репозитории `ub-mode-php`. Локальный каталог `work/` содержит материалы задач и исключён из Git в этой рабочей копии.

## Сборка, тестирование и разработка

Используйте PHP 8.2+ и Composer 2. Из корня репозитория запускайте `composer install`, `composer test` и `composer test-consumer`. Команда `php bin/ub-php --root fixtures check --format json` анализирует встроенные образцы. В проекте-потребителе установите эту рабочую копию как Composer path repository и запускайте `vendor/bin/ub-php doctor` или `vendor/bin/ub-php check --format json`.

## Стиль кода и имена

Соблюдайте PSR-12 и называйте классы PHP в `PascalCase`. Расчёты метрик оставляйте чистыми функциями, а извлечение AST — только для чтения. Сохраняйте стабильный порядок отчётов и проверяйте внешние данные до расчёта. Не выполняйте и не изменяйте анализируемый PHP-код. JSON-отчёт сохраняет версию схемы `1.0`.

## Тестирование

По возможности добавляйте тест поведения для изменений в разборе кода, выводе CLI, правилах метрик или отчётах до реализации. Делайте образцы фреймворков минимальными. Обязательный процент покрытия тестами не задан; отсутствующее покрытие Clover должно оставаться `unknown`. Стандартный порог известного CRAP — `< 10`; кандидаты Dryer считаются предупреждениями.

## Коммиты и Pull Request

Используйте короткие повелительные заголовки коммитов. В Pull Request объясняйте изменённое поведение, соответствующий раздел задачи или спецификации, выполненные тесты и изменения зависимостей или отчётов. Для изменений формата отчёта прикладывайте пример JSON. Не включайте в коммиты сгенерированные `.metrics/`, Composer `vendor/` и локальные файлы IDE.
